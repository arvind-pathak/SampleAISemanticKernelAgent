4. PLUGINS — KERNELFUNCTION TOOLS
HRPlugin & GreetingPlugin
👥
[KernelFunction]
HRPlugin
HR data access — leave balances & employee profiles
GetLeaveBalance(employeeName)
GetEmployeeInfo(employeeName)
Synonyms: leave / holiday / vacation / PTO / annual leave → same function
👋
[KernelFunction]
GreetingPlugin
Handles greetings and social conversation
SayHello()
Triggers: hi, hello, hey, good morning, howdy…
📋
system prompt file
agent-instructions.md
Agent persona, rules, synonym mapping loaded at startup
Skills/agent-instructions.md
HR persona · tone rules · synonym table
Each KernelFunction carries a [Description] attribute — GPT-4o-mini reads these to decide which function to call automatically (no manual routing code needed)
